# Бонусы A, B, C

Для запуска кода нужен Python 3.10+ и библиотеки из requirements.txt

## Запуск

```bash
python -m pip install -r requirements.txt
python bonus_a.py
python -m unittest -v
python bonus_b.py
```

Последняя команда печатает результаты трёх сценариев и создаёт четыре графика для отчёта.

```bash
python benchmark.py --max-n 8 > benchmark.csv
```

В `benchmark.csv` — фактические замеры при четырёх переменных. Полный метод проверяет каждое присваивание пакетами NumPy. Быстрый метод перебирает только наборы индикаторов. Условия запуска и число повторов указаны в отчёте и CSV. Скрипт замеров печатает сведения о своей среде в stderr. Для короткого пробного прогона используйте `--max-n 5` с выводом в терминал.
